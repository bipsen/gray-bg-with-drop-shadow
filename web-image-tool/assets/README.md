# Web Image Tool

This project is a web-based tool that allows users to upload images (PNG or JPEG) and process them for use in a CMS. The tool centers the uploaded image on a grey background, resizes it to 1000x720 pixels, and adds a drop shadow for a polished look.

## Features

- Upload images in PNG or JPEG format.
- Automatically centers images on a grey background with comfortable margins.
- Resizes images to 1000x720 pixels, accommodating both landscape and portrait orientations.
- Adds a drop shadow effect to the processed images.
- Allows users to download the final processed image directly from the browser.

## Usage

1. Open the `index.html` file in a web browser.
2. Use the upload interface to select an image file.
3. The tool will process the image and display it on the canvas.
4. Click the download button to save the processed image.

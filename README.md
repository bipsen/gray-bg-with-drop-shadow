# Web Image Tool

This project is a simple web tool that allows users to upload images (PNG or JPEG) and process them for use as front pages of PDF reports. The tool adapts the uploaded images by centering them on a grey background, resizing them to 1000x720 pixels, and adding a drop shadow. Users can then download the processed image directly from their browser.

## Features

- Upload images in PNG or JPEG format.
- Automatically centers images on a grey background with comfortable margins.
- Resizes images to 1000x720 pixels, accommodating both landscape and portrait orientations.
- Adds a drop shadow to the processed images.
- Allows users to download the final image directly.

## Project Structure

- `src/index.html`: Main HTML document for the web tool.
- `src/styles/style.css`: CSS styles for layout and design.
- `src/scripts/app.js`: JavaScript code for handling image uploads and processing.
- `assets/README.md`: Documentation related to the assets used in the project.

## Usage

1. Open `src/index.html` in a web browser.
2. Use the upload interface to select an image file.
3. The tool will process the image and display it on the canvas.
4. Click the download button to save the processed image to your device.

## Requirements

- A modern web browser that supports HTML5 and JavaScript.
